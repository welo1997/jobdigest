# Test tooling for the JobDigest half, layered on the deps the container actually ships.
#
# Exists because the two halves of this repo cannot share one environment and should not be
# forced to. The immediate trigger was a version conflict on shared libraries -- installing
# the root requirements and service/'s together is a ResolutionImpossible, which is exactly
# how .github/workflows/tests.yml failed on its first run. Later dependency PRs aligned
# beautifulsoup4 and anthropic, so today only feedparser actually clashes; the file stays,
# because the conflict was the symptom. The reason is that the root file drags snowflake and
# dbt into an environment JobDigest never ships.
#
# Keeping them apart also means the JobDigest tests run against the versions JobDigest
# deploys, rather than whichever version pip happened to settle on. Same boundary CLAUDE.md
# draws for the code: Snowflake must never reach into service/.
#
# Pins are duplicated from requirements-dev.txt on purpose -- that file is the market-intel
# side's tooling and drags the whole root stack in with `-r requirements.txt`.
